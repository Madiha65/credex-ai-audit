# AI Spend Auditor

AI Spend Auditor is a web application that helps startups and engineering teams identify unnecessary spending on AI tools like ChatGPT, Claude, Cursor, and GitHub Copilot.

The platform analyzes current subscriptions, compares pricing plans, and recommends cheaper alternatives or optimizations with estimated monthly and yearly savings.

## Features

- AI spend audit engine
- Personalized AI-generated summaries
- Shareable audit URLs
- Lead capture with email delivery
- Responsive UI
- Open Graph sharing support
